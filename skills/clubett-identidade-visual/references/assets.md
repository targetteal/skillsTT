# Biblioteca visual incluída

Todos os caminhos abaixo são relativos à pasta da skill. Veja o [inventário-fonte](inventario-fonte.md) para contexto e origem. Os arquivos são evidência visual ou originais de uso; sua presença não torna todo elemento obrigatório em uma peça nova.

## Marca

- `assets/identity/target-teal-logo-dark.png`: assinatura TT para fundo claro.
- `assets/identity/target-teal-logo-light.png`: assinatura TT para campo escuro ou teal apropriado.

## Linguagem narrativa do Clube

- `assets/narrative/travessia-hero.webp`: composição de travessia, elenco existente e espaço editorial.
- `assets/narrative/pertencimento.webp`: relação, gestos e experimentação entre pares.
- `assets/narrative/storm-paper.webp`: tensão, linha manual e vazio editorial.
- `assets/narrative/map-master.webp`: objeto mestre; manter suas características em edição localizada.
- `assets/narrative/crack-paper.webp`, `porto-seguro.webp`, `ship-release.webp`: ruptura, continuidade narrativa e edição localizada.

## Objetos e aplicação

- `assets/navigation/compass.png`, `club-map.png`, `wheel.webp`: objetos da narrativa. Use somente quando servirem à ideia.
- `assets/applications/social-card.png`: exemplo de aplicação; não é modelo obrigatório.

Não extraia marca de uma imagem composta se o arquivo de logo original estiver disponível. Não use uma referência de elenco como autorização para criar mascotes oficiais.
