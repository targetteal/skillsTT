# Fase 0 · Terreno

Antes de qualquer ideia, leia o material real. Abra as imagens, não só os nomes.

Entregue `terreno.md` no projeto com:
1. **Fontes lidas** (transcrição, relatório, dados, slides colados, apps) e o que cada uma dá ao filme.
2. **Arco provável** em 5–12 passos, na ordem da fala do usuário (transcrições de planejamento costumam já ter o arco).
3. **O que reaproveitar**: diagramas, pranchas, números oficiais, textos aprovados, identidade existente (tokens CSS, `design.md`, skill de marca).
4. **Restrições**: nomes proibidos na tela, dados sensíveis, tom, público, duração do momento, se haverá som na sala.
5. **Riscos do encontro** que mudam o filme (ex.: alguém chega atrasado → atalho de reentrada; alguém não recebeu o material → fala, não tela).

**Portão:** usuário confirma o arco e as restrições.
