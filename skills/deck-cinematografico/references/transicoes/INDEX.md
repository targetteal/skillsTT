# Biblioteca de transições

Catálogo **vivo**. Ele inspira, não limita. Regras:

1. **Comece pelo conteúdo, não pelo catálogo.** Para cada passagem entre planos, pergunte primeiro: *que objeto deste conteúdo pode virar o próximo?* (a pergunta vira ponto, o eixo vira fio, a seta vira impacto). Só depois consulte a biblioteca, para achar mecânica pronta ou uma variação.
2. **Todo projeto inventa pelo menos uma transição original.** Registre na ideação (`conceito.md`) qual é a candidata.
3. **Nenhuma transição mais de 2 vezes no mesmo filme.** Variar é parte da linguagem.
4. **Colheita:** ao entregar, cada transição nova vira uma ficha (use `_modelo.md`) e entra nesta tabela com a origem. Transições que se mostraram fracas ganham a nota "evitar" e o porquê.
